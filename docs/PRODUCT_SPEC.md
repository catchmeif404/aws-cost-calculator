# AWS 비용 계산기 — 제품 스펙

> 작성일: 2026-08-31

## 포지셔닝

AWS 공식 Pricing Calculator를 그대로 따라 만들지 않는다. 이미 있는 걸 복제하는 건 의미가 없다.

대신: **"개발자가 실제 서비스를 배포할 때 월 얼마 나오는지 빠르게 계산해주는 도구"**로 좁힌다.

- 세세한 파라미터(수백 개 옵션)를 다 받지 않는다.
- 개발자가 흔히 쓰는 조합(ECS Fargate, RDS, Redis, ALB, S3 …)을 빠르게 선택해서
- "대충 얼마 나오는지" + "어떻게 줄일 수 있는지"를 30초 안에 알려준다.

## MVP 기능 (Phase 1 — 로그인 없음)

### 1. 비용 계산기 (입력 → 견적)

**입력 예시**
- 런타임: Spring Boot API 등
- ECS Fargate: 인스턴스 수, vCPU/메모리
- RDS: 엔진(PostgreSQL 등), 인스턴스 타입
- ElastiCache Redis: 사용 여부, 노드 타입
- ALB: 사용 여부
- S3: 용량(GB)
- 예상 트래픽: 하루 사용자 수 (대략적인 데이터 전송량 추정에 사용)

**출력 예시**

```
예상 AWS 월 비용

ECS       $38
RDS       $32
Redis     $18
ALB       $17
S3         $3
----------------
합계      $108 / month
```

### 2. 비용 절감 제안 (규칙 기반 팁)

계산된 구성을 보고 조건부로 팁을 노출한다.

- ECS Fargate x86 → Graviton(ARM) 전환 시 예상 절감액
- RDS 인스턴스가 과도하게 큰 경우 다운사이징 권장
- NAT Gateway가 포함된 구성일 경우 비용 주의 경고
- (추후 추가: 예약 인스턴스/Savings Plans 안내, S3 스토리지 클래스 최적화 등)

→ 팁은 "if 구성 조건 then 메시지" 형태의 규칙 테이블로 관리 (초기엔 하드코딩, 이후 데이터화 고려).

### 3. 예산 → 아키텍처 역산

사용자가 예산을 입력하면, 그 예산 안에서 가능한 추천 구성을 보여준다.

**입력**: 예산 (예: ₩100,000/월)

**출력 예시**
```
추천 구성
ECS Fargate × 2
RDS t4g.micro
ElastiCache 제외
CloudFront + S3
```

→ 초기 버전은 몇 가지 프리셋 조합(스타트업 최소구성 / 트래픽 대응형 / DB 중심형 등) 중 예산에 맞는 걸 추천하는 방식으로 단순하게 시작. 완전 최적화 알고리즘은 나중.

### 4. 결과 공유 (바이럴 루프)

- 계산 결과를 고유 URL로 저장/공유 (docs/PROMOTION_STRATEGY.md 4장 참고)
- OG 이미지/메타태그로 공유 시 미리보기 제공

## Phase 2 (로그인 이후 — 실계정 연동)

**"내 AWS 계정을 연결해서 실제 사용량을 확인하고 줄일 수 있게"**

- AWS 계정 연결 (IAM Role, cross-account AssumeRole 방식 — access key 직접 저장 지양)
- 읽기 전용 권한만 요청 (Cost Explorer, 리소스 조회 API 등)
- 현재 실제 지출 내역을 대시보드로 시각화
- MVP의 "절감 팁 규칙"을 실제 계정 데이터에 적용해서 개인화된 절감 제안 제공

**보류 이유 (MVP에 포함하지 않는 이유)**
- IAM 보안 설계(권한 스코프, credential 저장/폐기 정책)가 필요해 개발 난이도가 급격히 상승
- AWS Cost Explorer API는 호출당 과금이라 원가 구조 설계가 선행되어야 함
- 첫 목표는 "빠른 출시 → 첫 1,000원"이므로, 이 기능 때문에 출시가 늦어지는 걸 피함

→ MVP 출시 후 사용자 반응을 보고 Phase 2 착수 여부를 결정한다.
