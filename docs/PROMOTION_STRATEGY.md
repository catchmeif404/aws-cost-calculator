## 0. 핵심 원칙

- 이 서비스는 **개발보다 홍보가 더 어렵다** → 처음부터 홍보 전략까지 포함해서 만든다.
- 첫 목표는 월 100만 원이 아니라 **진짜 1,000원**.
- 1,000원 → 1만 원 → 10만 원 → 100만 원 순으로 단계적으로 키운다.

## 3. 바이럴 루프 — 결과 공유 기능

서비스 자체에 "공유하기" 기능을 내장해서, **사용자가 쓰면서 자동으로 홍보가 되는 구조**를 만든다.

**흐름**

1. 사용자가 아키텍처(예: ECS + RDS + Redis + ALB)를 선택해서 계산
2. 결과 페이지 생성: "내 AWS 아키텍처는 월 $87입니다."
3. `[결과 공유하기]` 버튼 → 고유 링크 생성
4. 사용자가 개발 커뮤니티 등에 링크 공유
   - 예: "이 정도 규모면 AWS 한 달에 얼마 나올까요?"
5. 링크를 통해 신규 유입 발생 → 신규 사용자도 계산 후 공유 → 루프 반복

**필요 기능 (개발 스펙 메모)**

- 계산 결과를 고유 URL로 저장/공유할 수 있는 기능 (Slug 또는 short ID)
- 결과 페이지에 OG 이미지/메타태그 (공유 시 미리보기가 예쁘게 뜨도록)
- "나도 계산해보기" CTA로 재유입 유도
